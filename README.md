# Weather App

A simple weather application that allows users to search for a city and view its current weather information.

## Features

* Search weather by city
* Displays current temperature
* Shows weather conditions
* Fetches real-time data from a weather API
* Simple and responsive interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Weather API

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.

3. Open `index.html` in your browser.

## API

This project uses a weather API to fetch current weather data.

> Add your API provider name here, for example: OpenWeather API.
